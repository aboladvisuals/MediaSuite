# MediaSuite

**MediaSuite** is an interactive prototype for an all-in-one media production and church presentation desktop application.

The project explores a unified workflow where users can manage, edit and present media without switching between multiple applications.

## Prototype Features

- 🎬 **Video Studio** — video editing, combining clips and audio
- 🖼️ **Photo Studio** — batch photo editing and processing
- 📱 **iPhone Transfer** — simplified iPhone-to-PC media importing
- 📚 **Media Library** — centralised media management
- 🎵 **Songs & Lyrics** — organise and prepare worship lyrics
- 📖 **Bible** — search and prepare scripture for presentation
- 📋 **Service Planner** — organise the complete service running order
- 📺 **Live Projection** — Preview → Live → Projector workflow
- 🎨 **Themes & Branding** — church-specific presentation styling

### Core Workflow

**iPhone → Import → Media Library → Edit → Service Planner → Preview → Go Live → Projector**

## Current Status

🚧 **Interactive Prototype / Proof of Concept**

The current browser version demonstrates the proposed interface, navigation and user experience. It is not yet the final production application.

The planned production version will be developed as a Windows desktop application with real media processing, device integration, local storage and multi-display projection capabilities.
